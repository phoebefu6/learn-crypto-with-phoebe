# Learn Crypto with Phoebe: Crypto Markets as a Data Problem

Sixteen 45-minute sessions on the off-chain data of crypto markets: exchange tapes, order books,
candles, venues, indices and the volume that venues report about themselves. Six leader sessions
on what changes for a data decision, ten practitioner sessions on reading, building and testing
the data, ending in a bench that runs forensic wash-trade detectors (first-digit deviation,
roundness, size clustering) in the browser on a declared synthetic tape.

No coins, no prices, no venues named. Nothing here is investment advice.

- Open `index.html` in a browser; every page is static HTML with inline SVG.
- The engine is `assets/cm-live.js` (seeded, deterministic, self-testing on load).

By Phoebe Fu.
